05 • Findings

What the experiments revealed.

Six practical lessons translate the notebook results into decisions a data-science team can use.

+1.93

F1-point improvement

Switching from baseline ReLU to ELU created the strongest balanced gain.

81.04%

Best minority Recall

Weighted BCE captured more high-income cases but introduced more false positives.

78.58%

Highest Precision

Focal Loss was cautious: precise positive predictions, but only 41.88% Recall.

−4.27

BatchNorm F1 gap

Normalization was unnecessary for this shallow network with standardized inputs.

90.68%

Strong ranking ability

The winning ROC-AUC indicates reliable separation across probability thresholds.

≠

More is not always better

The combined model underperformed because individually useful techniques interact.

Decision framework

Choose the model for the cost of the mistake.

There is no universal winner without business context. The ELU model is the best balanced candidate. Weighted BCE is preferred when missing a true high-income case costs more than a false positive.

Balanced production modelUse ELU + Glorot Uniform + BCE + Adam
Recall-first campaignUse Weighted BCE and accept more false positives
Next optimizationTune the decision threshold using PR curves
06 • Implementation

Winning architecture.

A compact network produced the best generalization. The most complex configuration was not required.

best_model.pyPython 3.11
from tensorflow import keras
from tensorflow.keras import layers

model = keras.Sequential([
    layers.Input(shape=(X_train.shape[1],)),
    layers.Dense(128, activation="elu", kernel_initializer="glorot_uniform"),
    layers.Dense(64, activation="elu", kernel_initializer="glorot_uniform"),
    layers.Dense(1, activation="sigmoid")
])

model.compile(optimizer="adam", loss="binary_crossentropy", metrics=["accuracy"])
history = model.fit(X_train, y_train, epochs=50, batch_size=64, validation_split=0.1)
